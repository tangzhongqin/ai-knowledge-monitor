## 🎯 这个系统是干什么的

**解决的问题**：全球 AI 发展太快，信息过载，你不知道每天该关注什么。

**本系统做了什么**：
- 从 192,215 个 GitHub 用户中用 5 轮雪球采样 + AI 相关性筛选出 **2061 位 AI 创作者**
- 按 AI 深度/活跃度/影响力/领域覆盖 四维排序精选 **250 人**
- 每天自动扫描其中 **50 位 T1 核心创作者** 的 GitHub 仓库动态

**你怎么用**：花 3 分钟扫一眼「今日重点」，看到感兴趣的仓库点进去深读。

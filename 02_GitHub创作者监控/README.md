# 02_GitHub创作者监控

> 从 192k 人中筛选 2061 位 AI 创作者 → 多维排序精选 250 人 → 每日扫描 50 位核心创作者的 GitHub 动态。

## 命令入口

```bash
# 每日监控扫描（T1 50 人）
bash 02_GitHub创作者监控/scripts/monitor.sh

# 重新发现 + 筛选（从头跑，约 10 分钟）
# 见 scripts/discover.sh（待创建）
```

## 自动运行

- **macOS launchd**: 每天 9:00 自动跑
- **GitHub Actions**: 每天 UTC 1:00 云端跑（电脑关了也不漏）
- 报告位置: `02_GitHub创作者监控/reports/YYYY-MM-DD.md`

## 数据资产

| 文件 | 说明 | 人数 |
|------|------|------|
| `data/种子创作者名单.md` | 初始 67 位种子 | 67 |
| `data/全球AI创作者数据库.md` | 5 轮雪球采样全量 | 2061 |
| `data/精选250-AI创作者监控名单.md` | 多维排序精选 + 跨平台账号 | 250+48 |

## 方法论

```
67 种子 → 5轮雪球(192k) → 采样3000 → AI关键词筛选(2061)
→ 四维排序(AI深度+活跃度+影响力+领域覆盖) → 精选250
→ 8维度跨平台补充 → 298 总名单
```

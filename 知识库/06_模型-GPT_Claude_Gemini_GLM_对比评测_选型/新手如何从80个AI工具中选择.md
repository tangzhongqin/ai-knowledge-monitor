# 🧭 新手如何从80个AI工具中选择

---

## 📌 一句话总结

**按你的角色分层选工具：非创造者只需2个，创造者按"大脑—手—场景工具"三层架构选配，新手优先选免费额度充裕的国产工具。**

## 🔍 核心内容

### 第一步：判断自己的角色

- 如果你至今没接触过AI编程/创作工具，大概率你不是程序员或内容创造者。此时80个工具里**绝大多数与你无关**，集中精力用好2个核心工具即可。
- 如果你是创造者（做APP、小程序、项目、自媒体、设计），才需要分层选配。

### 第二步：三层架构选工具

原作者通过屏幕演示，将AI工具分为三个层级：

**层级一：思考大脑层（负责想清楚）**
- **Claude**：思维深度和广度最强，最严谨、遵守规则、道德约束最强。适合做项目的整体思考、发散性头脑风暴、架构搭建。被描述为"插在GPT上已经被调教好的"，做事情非常严谨。
- **ChatGPT**：同样可作为大脑使用，综合能力强。
- 本地模型（Hermes、llama等）：用于离线场景。

**层级二：执行双手层（负责做出来）**
- **Cursor**：国外编程创作首选，被马斯克收购（注：实际Cursor未被收购，原作者可能混淆）。
- **Codex**：OpenAI 推出的终端级编程 Agent，侧重自主执行能力。
- **Qoder / OpenCode**：国内编程创作的好选择。
- **TRAE SOLO CN**：字节跳动出品，对中文友好，可外接模型（如买的其他 coding plan），目前有免费额度，适合新手从零到一的项目开发。

**层级三：场景工具层（负责具体工作流）**

| **QoderWork CN** | 阿里 | 办公/解决问题型AI | 内置千问3.7Max，贴合度极好 |

### 原作者的核心推荐

1. **海外首选**：Cursor（编码）+ Claude（思考）
2. **国内首选**：WorkBuddy 或 QoderWork CN（办公/内容创作），千问3.7Max 模型是目前国内最强，没有之一
3. **长任务首选**：Kimi Code，在指令级工具和多步推理上超过其他工具
4. **新手首选**：TRAE（免费额度 + 中文友好 + 可外接模型）
5. **内容创作**（公众号、小红书、调研分析、深度分析、生成功能）：WorkBuddy / QoderWork 质量最高

## 🧠 专家升华

### 一、技术深度分析：原作者框架的合理性

原作者的"大脑—手—场景工具"三层架构，本质上对应的是 AI 工具链的三个计算范式：

1. **推理层（Reasoning Layer）**：Claude / ChatGPT 负责的是**非确定性推理**——开放域思考、架构设计、策略分析。这类任务需要模型具备强大的上下文理解、逻辑链构建和多角度权衡能力。Claude 的 RLHF 训练使其在这方面确实更"严谨"，但这同时也意味着它在创意自由度上可能不如 GPT。

2. **执行层（Execution Layer）**：Cursor / Codex / TRAE 负责的是**确定性代码生成**——将明确的规格转化为可运行的代码。这里的关键差异不在于模型能力，而在于**工具链集成深度**（是否支持终端命令、文件系统操作、Git 工作流、外部模型接入）。

3. **场景层（Application Layer）**：WorkBuddy / QoderWork 负责的是**领域特化任务**——它们不是在比模型强，而是在比"谁更懂这个场景的数据格式和工作流"。比如小红书的文案风格、公众号的排版规范、调研报告的结构模板。

### 三、行业位置判断

当前（2026年中）AI工具市场处于**从工具期向平台期过渡**的阶段：

- **海外**：Cursor + Claude Code + Codex 已形成"IDE Agent + Terminal Agent + 通用编程 Agent"的三足鼎立，竞争焦点从"谁能写代码"转向"谁能管理完整项目"。
- **国内**：字节（TRAE）、阿里（QoderWork/通义灵码）、美团（WorkBuddy）、腾讯（CodeBuddy/元宝）、月之暗面（Kimi）各有布局，但**模型能力仍然是核心瓶颈**——腾讯和美团的工具好但模型弱，阿里的模型强（千问3.7Max）但工具生态不如字节。
- **关键趋势**：外接模型能力正在成为标配（WorkBuddy、TRAE均已支持），这意味着工具和模型正在解耦——未来最好的组合可能是"字节的工具 + 阿里的模型"或"开源框架 + 任意模型"。

### 四、实操建议

1. **新手零成本入门路径**：TRAE（IDE）→ WorkBuddy（办公）→ 根据需求决定是否上 Claude Code 或 Codex
2. **不要同时学多个工具**：每个工具的操作逻辑和快捷键体系不同，同时学3个以上会严重降低效率。选定1个主力工具用满2周再评估。
3. **模型外接是第一优先级能力**：选择工具时，是否支持外接外部模型比工具本身的功能更重要。因为模型迭代速度远超工具迭代速度。
4. **国产工具的核心优势不是技术而是"免折腾"**：不需要解决网络问题、支付问题、英文文档阅读问题。对大多数非技术用户，这点比模型能力强10%更重要。
5. **忽略工具数量的焦虑**：80个工具里真正值得关注的不到10个。其余70个要么是细分领域的变体，要么很快会被大厂整合掉。

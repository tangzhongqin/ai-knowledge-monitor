# 从 Claude 到 Codex：八大桌面 Agent 锐评对比

**来源**: 抖音视频 (2026-07-23) | **作者评级体系**: 夯爆了 > 夯 > 强 > NPC > 拉完了

---

## 一句话总结

2026 年中桌面 Agent 战场全景横评：OpenAI Codex 凭借多模态全栈能力登顶，Claude Code 以 DeepSeek 国产模型适配 + 视觉识别成为最广泛使用的工具，Cursor 从先驱沦为追赶者，而腾讯的 Qclaw 成为唯一被明令"千万不要用"的产品。个人推荐的最强组合是 Obsidian + Claudian + Hermes 的知识库 Agent 栈。

## 核心内容

### 筛选标准

作者设定了三条硬门槛，确保评测对象聚焦于真正实用的桌面 Agent：

| # | 标准 | 含义 |
|---|------|------|
| 01 | **纯桌面端** | 必须是桌面端原生工具，非网页版包装 |
| 02 | **人人可用** | 不限于编程场景，小白也能用于日常办公 |
| 03 | **全能顺手** | 操作便捷，能覆盖多种任务类型 |

### 八大 Agent 逐一实评

#### 1. Trae（字节跳动） -- 评价：NPC

- 对新人极其友好，免费下载装完即用，无需本地部署模型
- 支持挂载文件夹、安装扩展
- **硬伤**：免费模型需要排队，高峰期体验明显下降
- 定位：小白入门跳板，用完就该升级

#### 2. Qclaw（腾讯/微信） -- 评价：拉完了

- 微信团队出品，实际是 OpenClaw 的魔改版
- 作者原话："说实在的一点都不好用"
- **明确建议**：要么用原始版 OpenClaw，要么直接用 WorkBuddy，"千万不要用这个"
- 全场唯一被直接劝退的产品

#### 3. WorkBuddy（腾讯） -- 评价：强

- 功能丰富，更偏向办公场景（文档处理、流程自动化、日常事务）
- **缺点**：配置项多，上手门槛较高；"东西太多不知道该怎么配置"
- **优点**：一旦配置到位，日常办公完全够用
- 定位：个人和小白用户的办公 Agent

#### 4. 悟空（阿里） -- 评价：NPC

- 面向团队和企业，将整个企业化流程内置
- 与 WorkBuddy 形成清晰分工：WorkBuddy 给个人，悟空给企业
- 做企业系统流程编排选悟空，个人用户无需考虑

#### 5. Cursor（Anysphere） -- 评价：强

- 曾经的王者，"以前用得最多"
- **问题**：Codex 和 Claude Code 更新太快，Cursor 的相对优势被大幅削弱
- 干活依然很强，但"勉强给个强"——领先地位不再
- 最早定位编程工具，现在被迫向通用 Agent 转型

#### 6. Claude Code（Anthropic） -- 评价：夯

- **当前用户量最大的桌面 Agent**，"配国产大模型 DeepSeek" 是杀手锏
- 视觉识别能力突出，"加上视觉识别的话强到飞起"
- 支持第三方模型后端（DeepSeek 等），对中国用户极友好
- Anthropic 开放模型接口的策略被证明极为成功

#### 7. Codex（OpenAI） -- 评价：夯爆了

- 作者首推产品，"没什么好说了，夯爆了"
- 全能型：写文章、做视频、做图片、写代码都非常强
- **唯一缺点**：上手有一定门槛
- 作者强烈建议："一定要用起来"
- 代表了 OpenAI 从 Chat 到 Agent 的关键战略转型

#### 8. Obsidian + Claudian + Hermes（作者私人推荐） -- 评价：夯爆了

- 非单一产品，而是个人工具栈：Obsidian（知识库）+ Claudian（Claude 桌面集成）+ Hermes（自进化 Agent 框架）
- Obsidian 配合各种 Skill 和记忆功能，形成"第二个我"
- 加上 Hermes 的自进化能力后"帅气到飞起"
- 这是全场定制化程度最高、上限最高的方案

## 专家升华

### 一、行业格局分析（2026 年 7 月）

2026 年中，桌面 Agent 市场已从"编程辅助工具"彻底演变为"通用桌面智能代理"赛道。几个关键趋势：

1. **从 IDE 插件到桌面原生的范式迁移**：Cursor 作为 IDE 时代的定义者，正被 Claude Code 和 Codex 这类桌面原生 Agent 超越。桌面 Agent 可以操作系统级功能（文件管理、多应用协同、屏幕识别），这是 IDE 插件无法触及的能力边界。

2. **模型后端的可替换性成为核心竞争力**：Claude Code 支持 DeepSeek 是其在中国市场用户量最大的核心原因。用户不想被锁定在单一模型供应商。Codex 目前仅支持 OpenAI 自家模型，长期来看这是一个策略风险。

3. **中国大厂的"多胎策略"**：腾讯同时布局 Qclaw（失败）和 WorkBuddy（成功），阿里推悟空（企业）+ 通义系列，字节有 Trae（入门）+ 豆包生态。这种赛马机制意味着至少一半产品会是炮灰。

4. **个人知识库 + Agent 的组合拳正在成为终极方案**：作者推荐的 Obsidian + Claudian + Hermes 栈代表了 Power User 的方向——用本地知识库做长期记忆，用 Agent 做任务执行。这与 MemPalace + Claude Code 的思路一致。

**评分说明**：
- **编程能力**：代码生成质量、多文件重构、调试能力、语言覆盖度
- **易用性**：安装配置难度、学习曲线、界面直观度
- **中文支持**：中文理解质量、中文文档、中国本地化适配（含模型网络可达性）
- **性价比**：免费额度、订阅价格 vs 能力、是否可用国产模型降本
- **生态完善度**：插件/扩展/Skill 数量、社区活跃度、第三方集成
- **综合**：加权平均（编程 25% + 易用 20% + 中文 20% + 性价比 20% + 生态 15%）

**关键解读**：
- **Claude Code 综合评分最高（8.7）**，胜在均衡——编程强 + 中文好 + 可用 DeepSeek 降低成本 + 易用性不错
- **Codex 编程单项最强（9.5）** 但易用性和性价比拉低了综合分。OpenAI 的多模态能力（写文章 + 做视频 + 做图）是其差异化优势
- **Trae 是被低估的入门之选（7.7）**，虽然功能有限，但免费 + 零门槛 + 中文友好，作为"第一个桌面 Agent"完全合格
- **Obsidian 组合上限最高但门槛也最高（5.0 易用性）**，不适合推荐给普通用户

### 三、逐工具深度技术分析

#### Codex（OpenAI）-- 多模态 Agent 的新标杆

**技术架构推测**：Codex 大概率基于 GPT-5 系列模型，原生支持文本、图像、视频、代码的多模态输入输出。与 ChatGPT 的最大区别在于它获得了桌面级系统权限——可以操控文件系统、调用应用、截屏识别、执行脚本。

**核心优势**：
- 多模态生成能力行业第一（文字 + 图片 + 视频一条龙）
- OpenAI 的代码训练数据规模和质量遥遥领先
- 与 OpenAI API 生态无缝对接（Function Calling、Assistants、GPTs）

**潜在风险**：
- 模型锁定——只能用 OpenAI 自家模型，无法切换到 DeepSeek 或 Claude
- 中国用户面临网络障碍和支付障碍
- 上手门槛确实偏高，对小白不够友好

**替代方案**：如果看重多模态能力但需要中文友好，可以关注智谱 GLM-5.2 的桌面端产品。

#### Claude Code（Anthropic）-- 中国市场的事实标准

**技术架构**：Claude Code 采用了模型无关的 Agent 框架设计——Agent 逻辑层与模型后端解耦，因此可以接入 DeepSeek、GLM 等第三方模型。这是 Anthropic 最聪明的架构决策。

**核心优势**：
- 视觉识别（Computer Use）是 Anthropic 从 2024 年就开始深耕的能力，领先行业至少一年
- DeepSeek 适配意味着中国用户零成本使用顶级 Agent 框架
- 用户量最大意味着社区资源、配置模板、问题解答最丰富

**不足**：
- Anthropic 自有模型的 API 价格仍然偏高
- 多模态生成（尤其是图片/视频生成）不如 Codex

**最佳实践**：Claude Code + DeepSeek-V3 做日常编码和办公，Claude Code + Claude Opus 做复杂推理和视觉任务。这是目前性价比最高的方案。

#### Cursor（Anysphere）-- 先驱者的困境

**技术分析**：Cursor 的困境是商业模式决定的。它本质上是 IDE（VS Code Fork）+ 模型 API 的中间层，而 Claude Code 和 Codex 是桌面原生应用。当模型能力差距不大时，谁的 Agent 框架更深地嵌入操作系统，谁就赢。

**Cursor 仍有优势的场景**：
- 深度编码项目（它的 IDE 集成度仍然最高，代码索引和上下文管理优于 Claude Code）
- 已有 VS Code 工作流的团队（迁移成本为零）
- 需要精细控制代码修改的场景

**建议**：纯编码任务 Cursor 仍然是非常好的选择，不要被排名误导。但如果你的需求超出了编码（文档、图片、流程自动化），Claude Code 或 Codex 更合适。

#### Obsidian + Claudian + Hermes -- Power User 的终极方案

这是全场最有价值的推荐，也是最容易被忽视的。

**技术栈拆解**：
- **Obsidian**：本地 Markdown 知识库，通过插件系统可以实现向量检索、知识图谱、Spaced Repetition。作为 Agent 的长期记忆层。
- **Claudian**：将 Claude API 接入桌面工作流的中间件，可以实现笔记自动整理、内容摘要、关联推荐。
- **Hermes**：自进化 Agent 框架——每完成一次复杂任务，自动生成 SKILL.md 记录下来，下次执行同类任务直接调用 Skill。这是真正的"越用越强"。

**为什么这个组合是"夯爆了"级别的**：
1. 知识不会丢失——Obsidian 本地存储，不受云端服务变更影响
2. Agent 会自我进化——Hermes 的 Skill 积累机制让系统随时间增长能力
3. 完全定制化——不像 Codex 或 Claude Code 有固定功能边界，这个栈可以无限扩展
4. 隐私安全——核心数据本地化，模型调用可选本地 Ollama

**缺点**：搭建和维护成本极高，需要较强的技术能力。普通用户请勿轻易尝试。

#### WorkBuddy（腾讯）-- 办公场景的务实之选

WorkBuddy 代表了腾讯对"AI + 企业办公"的理解。它不像 Codex 那样全能，但在文档处理、会议纪要、流程审批等办公场景上有针对性优化。

**与作者评价的差异**：作者给 WorkBuddy "强"的评级，我认为这个评级准确。它不是革命性产品，但在其定位场景（办公自动化）中表现扎实。配置复杂度确实是个问题——腾讯需要在"功能丰富"和"开箱即用"之间找到更好的平衡。

#### Trae（字节跳动）-- 被低估的入门神器

我比作者更看好 Trae。原因：
- 在"让更多人用上 Agent"这件事上，Trae 做得最好——免费、零配置、中文优先
- "免费模型排队"是成本结构问题，不是产品能力问题。如果字节愿意投入更多算力，这个缺点可以消除
- Trae 的战略价值是培养用户习惯——今天用 Trae 的小白，明天就是 Codex/Claude Code 的潜在用户

**建议**：如果你从未用过任何桌面 Agent，从 Trae 开始，一个月后再决定是否升级。

#### 悟空（阿里）-- 企业钉钉生态的 Agent 层

悟空的存在意义是补全阿里的"钉钉 + 通义 + 阿里云"企业 AI 版图。个人用户完全可以跳过。对于已经深度使用钉钉和阿里云的企业，悟空是自然的选择——流程集成度是其他 Agent 无法比拟的。

#### Qclaw（腾讯/微信）-- 腾讯的耻辱产品

一个产品被评价为"千万不要用"，通常意味着它不是做得不够好，而是做得比不用还糟糕。Qclaw 的问题推测：
- 微信团队对 OpenClaw 的魔改破坏了原有架构
- 可能捆绑了微信生态的限制（如必须扫码登录、数据必须经过微信服务器）
- 更新维护跟不上，沦为 KPI 产物

**替代方案**：直接用 OpenClaw 原始版，或者用 WorkBuddy。两者都比 Qclaw 好得多。

### 四、更优方案推荐

根据不同用户画像，我的推荐矩阵如下：

| 用户画像 | 首推方案 | 备选 | 理由 |
|----------|----------|------|------|
| **编程为主** | Cursor 或 Claude Code | Codex | 代码索引和重构能力是关键 |
| **全栈创作者**（文章+图片+视频） | Codex | Claude Code + 独立图片/视频工具 | Codex 多模态一体化的体验无可替代 |
| **中国用户/性价比优先** | Claude Code + DeepSeek | Trae（入门）| 国产模型降本 + 无需 VPN |
| **办公白领** | WorkBuddy | Claude Code | 办公场景针对性优化 |
| **Power User/极客** | Obsidian + Claudian + Hermes | Claude Code + MemPalace + ChromaDB | 定制化 + 自进化 |
| **企业团队** | 悟空（阿里系）或 Claude Code Team | Codex Enterprise | 看现有技术栈 |
| **纯小白/第一次尝试** | Trae | WorkBuddy | 零门槛，先上车再说 |

### 五、行业预判（2026 H2 - 2027）

1. **桌面 Agent 将分化出三个子赛道**：编程 Agent（Cursor/Claude Code）、办公 Agent（WorkBuddy/Copilot）、通用 Agent（Codex）
2. **模型后端无关化将成为标配**：不支持第三方模型的 Agent 会在中国市场被淘汰
3. **个人知识库 + Agent 的组合将成为 Power User 的标准配置**：Obsidian/Notion/Logseq + Agent 框架
4. **大厂的"赛马"策略将收敛**：腾讯可能合并或砍掉 Qclaw，字节可能将 Trae 整合进豆包生态
5. **OpenAI 的模型锁定策略将面临考验**：如果 Codex 不开放第三方模型，中国市场可能被 Claude Code 彻底占领

### 六、实操建议

1. **不要只看排名选工具**：Codex 排名第一，但如果你的主力场景是中文办公，Claude Code + DeepSeek 才是最优解
2. **Trae 是极好的入门工具**：被评 NPC 不代表它没用，对从未接触 Agent 的人来说，零门槛 > 功能强大
3. **Qclaw 确实不要碰**：作者说"千万不要用"是真的，不是标题党
4. **Obsidian + Agent 栈值得投资**：如果你愿意花时间搭建，长期收益远超任何单一产品
5. **关注模型后端的可替换性**：选择 Agent 工具时，优先选择支持多模型后端的（Claude Code、Cursor），避免被锁定

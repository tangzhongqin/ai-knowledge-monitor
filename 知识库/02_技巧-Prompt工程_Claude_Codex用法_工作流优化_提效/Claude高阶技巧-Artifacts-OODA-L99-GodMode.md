### 实战示例（来自视频演示）

**OODA 的完整推理链路——以"10天内备考"为例：**

- **Observe（观察）**：Day 0，花 30 分钟列出所有科目、考试日期、难度等级、可用时间块、手机干扰源
- **Orient（定向）**：建立优先级矩阵（硬课 50% 时间，中等 35%，简单 15%）；划分阶段（Day 1-4 学习新知 → Day 5-7 主动回忆 → Day 8-9 弱点回顾 → Day 10 轻松复习）
- **Decide（决策）**：输出每日精确到小时的日程模板（6:30-9:00 最硬科目深度专注 → 9:15-11:30 第二优先 → 下午第三科目 → 21:00-21:30 每日回顾）
- **Act（执行）**：手机放另一个房间、番茄钟 50/10、每天仅午餐时段允许查看手机、主动回忆替代被动重读

**/L99 的专家级输出——以"30天内用 AI 工具建立副业收入"为例：**
- 给出具体时间线而非泛泛建议
- 包含定价模型（$150-300/篇，$800-1500/月 retainer）
- 含 DM 话术模板、目标客户画像（LinkedIn 5000 粉丝以下的小创业者）
- 提供可交付物的具体规格（1000 字博客，H2 结构，指定语调）

## 🧠 专家升华

### 一、技术本质：这些"秘密指令"到底是怎么工作的？

这些指令**不是 Claude 官方功能**，而是**自定义指令（Custom Instructions）或 Project 级别的 System Prompt 注入**。它们的机制是：

1. **Slash Command 路由**：在 Claude 的 Projects 功能中，你可以将自定义指令保存为 Markdown 文件。当输入 `/command` 时，Claude 读取对应文件内容，将其注入为 System Prompt 前缀。这是 Anthropic 官方支持的 Projects 自定义指令机制。

2. **Persona Priming（人格启动）**：`/L99`、`/ghost`、`/critical` 等本质上是一种"角色启动提示词"。它们在 System Prompt 层面告诉模型"你现在是一个顶级专家""请用人类化表达"，这会改变模型的 token 概率分布——模型会被引导向特定风格和深度的输出空间。这与 Few-shot Prompting 的本质相同，但通过 System Prompt 注入效果更强（因为 System Prompt 的权重高于 User Message）。

3. **框架注入（Framework Injection）**：`/OODA` 属于结构化思维框架注入。它让 Claude 不只是在表层回答问题，而是强行套用特定推理结构。OODA 框架（由美军上校 John Boyd 提出）原本用于空战决策，其核心是"决策速度 > 原始信息量"——这也是它在 AI 交互中有效的根本原因：它强制 AI 先观察现状、再构建心智模型、再做决策、最后执行，避免了 AI 直接跳到"给答案"的惯性。

4. **Artifacts 的底层是代码生成 + 沙箱渲染**：`/artifacts` 指令激活的是 Claude 的 Artifacts 特性——Claude 生成 HTML/CSS/JS/React 代码并在侧面板实时渲染。它的本质是让 LLM 从"文本生成器"变成"交互式应用生成器"。

### 二、为什么 OODA + AI 是最被低估的组合？

大多数用户使用 AI 的方式是"问 → 答"，缺少中间推理环节。OODA 框架改变了这个范式：

- **普通模式**：用户说"帮我做学习计划" → AI 直接输出一个泛化的学习计划
- **OODA 模式**：用户说"/OODA 10天备考" → AI 先要求你提供现状信息（Observe）→ 建立优先级模型（Orient）→ 给出精确到小时的决策（Decide）→ 附执行规则和自我纠正机制（Act + Loop）

核心区别：OODA 让 AI 从一个"答案机器"变成**持续迭代的决策伙伴**。这对产品经理、创业者、学生等需要复杂规划的角色极其有价值。

### 三、/L99 和 /god mode 的区别与风险

- **/L99**：追求"极高专业水平"——输出的深度、精确度、结构完善度都拉到最高。适合需要专家级分析但不需要突破安全边界的场景。
- **/god mode**：追求"最具攻击性和全面性"——这可能涉及更主动的推测、更激进的建议、甚至绕过某些默认的谨慎约束。**使用时需要注意**：越激进的模式越容易产生幻觉和过度自信的错误。

### 四、实操建议：如何在日常工作中编排这些指令

**推荐的组合工作流：**

```
场景：从零启动一个新项目
1. /L99        → 获取专家级市场/技术概览
2. /OODA       → 制定战略和执行计划
3. /artifacts  → 构建可视化原型/数据看板
4. /critical   → 让 AI 批判性审视你的方案
5. 迭代循环    → 每周 /OODA 复盘，调整方向
```

**保存这些指令到你的 Claude Project：**
创建自定义指令文件（如 `L99.md`、`OODA.md`），内容为你希望注入的 System Prompt。这样在全球任何对话中都可以通过 `/L99` 等调用。
